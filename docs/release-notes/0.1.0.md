First release. Plug in an Android phone, choose **File transfer** on it, and it appears in Finder and on the desktop like a USB drive — browse with thumbnails, copy files both ways, eject, unplug.

**Requirements:** macOS 26 or later, Apple Silicon. macFUSE is included; the setup window installs it for you.

### Install

1. Download `Droidmount-0.1.0.dmg`, drag **Droidmount** to **Applications**.
2. Open it. Because Droidmount is not signed with a paid Apple developer certificate, macOS blocks it the first time: **System Settings → Privacy & Security → "Droidmount was blocked…" → Open Anyway**. Only once.
3. Follow the setup window: install macFUSE (asks for your password once), allow its file system extension in System Settings (switch the list to **By Category** → **File System Extensions** ⓘ → turn on **macFUSE** and **macFUSE (local)**), start at login.
4. Plug in your phone, **unlock it**, choose **File transfer**.

### What's in it

- Any Android phone over MTP, detected by its USB interface — no vendor list.
- Fast folder listing (one request per folder instead of one per file) and folder listings that never wait behind file copies.
- Safe copying to the phone: the old file is replaced only after the new one has arrived; failed copies are kept in **Unsent files** with a notification.
- macOS's hidden files (`.DS_Store`, `._*`, `.fseventsd`, …) never end up on the phone.
- Menu bar app: status, Open in Finder, Eject, Read-only, Start at login, setup assistant, hints when the phone is locked or not in File transfer mode.
- App icon that follows the macOS icon style (light, dark, clear, tinted).

### Known limitations

- Tested on a Pixel 9 Pro and a Samsung Galaxy phone so far — reports from other phones are very welcome.
- One phone at a time.
- Speed is limited by MTP and the cable (about 5–20 MB/s with USB 2 cables).
- Some phones only report a generic name over USB, e.g. "SAMSUNG_Android".

Verify the download: `shasum -a 256 Droidmount-0.1.0.dmg` must match `Droidmount-0.1.0.dmg.sha256`.
