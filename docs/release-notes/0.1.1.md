Droidmount now updates itself, and Quit works again.

### What's new

- **Automatic updates.** Droidmount asks once whether to check for updates automatically, then looks once a day and offers each new version with its release notes; you can also choose **Check for Updates…** in the menu. Updates are signed, and a download that does not match the signature is refused.
- **Quit no longer hangs.** Choosing Quit from the menu bar left Droidmount stuck; it now unmounts the phone and exits within a few seconds.

### Updating from 0.1.0

0.1.0 cannot update itself yet, so install this version by hand once: quit Droidmount (if it hangs, which is the bug fixed here, use **Force Quit**, ⌥⌘⎋), download `Droidmount-0.1.1.dmg`, drag **Droidmount** to **Applications** and replace the old copy — or, with Homebrew, `brew upgrade --cask tursithepanda/tap/droidmount`.

Because it is a new download, macOS asks for **Open Anyway** once more (System Settings → Privacy & Security). Updates that Droidmount installs itself skip that step.

Verify the download: `shasum -a 256 Droidmount-0.1.1.dmg` must match `Droidmount-0.1.1.dmg.sha256`.
